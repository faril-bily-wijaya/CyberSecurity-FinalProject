# Final Project Cyber Security - GDG OC UNSRI 2025/2026

Repositori ini adalah dokumentasi, skenario pengujian, dan implementasi teknis yang dibagi ke dalam tiga domain utama keamanan siber. Setiap domain memiliki scope (ruang lingkup) dan langkah pengerjaan teknisnya masing-masing.

## Tenggat Waktu (Deadline)

Batas akhir pengumpulan proyek ini adalah tanggal **11 September 2026**. Pastikan seluruh pekerjaan telah diselesaikan dan diunggah ke repositori sebelum tanggal tersebut.

## Mekanisme Pengumpulan Proyek

Untuk mengumpulkan tugas Final Project, setiap peserta wajib mengikuti tata cara pengumpulan berikut agar repositori tetap terstruktur rapi:

1. Tentukan  yang mw  dikerjakan (Red Team, Blue Team, atau Fusion).
2. Masuk ke dalam folder  yang dipilih tersebut.
3. Buat folder baru di dalamnya. Beri nama folder tersebut dengan nama Anda atau nama tim Anda.
4. Di dalam folder buatan Anda tersebut, Anda **wajib** membuat satu file `README.md`. File ini digunakan untuk menuliskan laporan, *write-up*, metodologi, atau penjelasan detail mengenai proyek yang Anda kerjakan.
5. Jika proyek Anda memiliki *source code*, *script*, gambar tangkapan layar (PoC), sampel, atau *resource* pendukung lainnya, seluruh file tersebut **harus** dimasukkan ke dalam folder yang sama dengan `README.md` milik Anda. Jangan menaruh *resource* di luar folder Anda.
